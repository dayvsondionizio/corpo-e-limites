# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/442b10b0-80f2-4b6c-befa-23796ea24cdb

## 🛡️ Corpo e Limites - App para Terapia Ocupacional

Este aplicativo é uma ferramenta interativa projetada para auxiliar Terapeutas Ocupacionais (TO) no ensino de limites corporais e segurança para crianças.

## ✨ Novas Funções (v1.1)
- **🔊 Sistema de Voz:** O app agora fala as frases de segurança e instruções (Web Speech API).
- **🎈 Exercício de Respiração:** Módulo interativo para autorregulação emocional.
- **🏰 Castelo Interativo:** Mapa corporal falante para ensinar zonas de proteção.
- **🤖 Insights Gemini:** Sugestões terapêuticas geradas por IA (opcional).

## 🚀 Como Hospedar (Vercel)
1. Conecte seu repositório GitHub à Vercel.
2. O comando de build deve ser: `npm run build`.
3. O diretório de saída deve ser: `dist`.

## 🛠️ Configuração Local
1. Execute `npm install`.
2. Execute `npm run dev`.
